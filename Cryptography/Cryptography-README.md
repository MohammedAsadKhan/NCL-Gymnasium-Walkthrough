## What to Expect in NCL Cryptography

NCL Cryptography challenges test your ability to identify and decode various encoding schemes and ciphers. You'll encounter everything from ancient substitution ciphers to modern encoding formats. The key skill is being able to recognize what type of encoding or cipher you're dealing with before trying to crack it.

> 💡 Your best friend for this entire category is **[CyberChef](https://gchq.github.io/CyberChef/)** and **[dCode.fr](https://www.dcode.fr/en)**. Get comfortable with both before the Individual game.

## Cryptography Quick Reference

**Identify unknown encodings fast:**
- Looks like random letters/numbers? Try Base64 on CyberChef
- Only letters A-Z with shifted alphabet? Likely Caesar/ROT cipher
- Dots and dashes? Morse code
- Only 0s and 1s? Binary
- 0-9 and A-F? Hexadecimal
- Looks like a URL with %20 style codes? URL encoding

**CyberChef magic trick:**
Paste your encoded text into CyberChef and use the **"Magic"** operation. It'll automatically detect the encoding and decode it for you. Great for when you're not sure what you're looking at.

