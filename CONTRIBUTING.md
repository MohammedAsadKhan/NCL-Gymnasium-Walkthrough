# Contributing to ICS NCL Walkthroughs

Thanks for helping make the team stronger! Here's how to add or improve walkthroughs.

---

## ✅ Before You Write

- Make sure the challenge isn't already covered (check the category folder)
- Complete the challenge yourself first — don't write a walkthrough from memory
- Use the template at `templates/challenge-template.md`

---

## 📝 Writing a Walkthrough

1. Copy `templates/challenge-template.md` into the correct `Category/difficulty/` folder
2. Name the file clearly: `challenge-name.md` (use lowercase, hyphens for spaces)
3. Fill out **every section** — especially ⚠️ Accuracy Tips
4. Be specific with commands and steps — assume the reader is a beginner

---

## 📤 Submitting

1. Fork this repository
2. Add your walkthrough file
3. Open a Pull Request with the title: `[OSINT/Easy] Challenge Name Walkthrough`
4. A CTF Coordinator will review and merge it

---

## 🚫 Rules

- **No flags from active NCL games** — Gymnasium only
- Keep walkthroughs educational, not just answer sheets
- Credit your sources if you used external references

---

*Questions? Ask in the ICS Discord `#ctf-help` channel.*
